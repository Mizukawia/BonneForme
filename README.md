
# Bonne Forme — Telegram Demo Bot

Демонстрационный Telegram-бот для Pilates Studio Bonne Forme.

## Что уже работает

- выбор языка RO / RU;
- главное меню;
- направления Pilates;
- сценарий записи:
  - направление;
  - формат;
  - дата;
  - время;
  - имя;
  - телефон;
  - подтверждение;
- раздел абонементов;
- информация о студии;
- контакты;
- опциональная отправка заявки администратору в Telegram.

## Быстрый запуск

### 1. Создайте бота через @BotFather
Получите токен.

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Задайте переменную окружения

Windows PowerShell:
```powershell
$env:BOT_TOKEN="ВАШ_ТОКЕН"
python main.py
```

macOS/Linux:
```bash
export BOT_TOKEN="ВАШ_ТОКЕН"
python main.py
```

### 4. Чтобы заявки приходили вам
Узнайте свой Telegram chat_id и добавьте:

Windows PowerShell:
```powershell
$env:ADMIN_CHAT_ID="ВАШ_CHAT_ID"
```

macOS/Linux:
```bash
export ADMIN_CHAT_ID="ВАШ_CHAT_ID"
```

После этого каждая подтверждённая демо-заявка будет приходить администратору.

## Railway

Переменные:
- `BOT_TOKEN`
- `ADMIN_CHAT_ID` — необязательно

Start Command:
```text
python main.py
```
